# Modèle de menaces

- ZK : mauvais statement, verifier ou contexte.
- FHE : autorisation trop large, clé réutilisée, absence de révocation.
- Base / OP Stack : séquenceur, dérivation, disponibilité L1, clés admin.
- HyperEVM : replay cross-chain, nonce réutilisé, signature expirée.

Contrôles communs : chain ID, domaine de signature, nonce, expiration, séparation des rôles et disponibilité des données.
